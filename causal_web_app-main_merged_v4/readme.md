# 因果图 交互式生成

## 项目概述
这是一个用于创建、编辑和可视化因果图的 Web 应用程序。它使用 Flask 作为后端框架，NetworkX 和 CausalNex 用于图的构建和操作，PyVis 用于生成交互式可视化。

## 目录结构
```
causal_web_app/
├── app.py                # 主 Flask 应用程序（功能实现代码一）
├── logs/                 # 日志文件夹
├── static/               # 静态文件夹（CSS、JS、HTML）
│   ├── causal_graph.html # 可视化输出文件
│   ├── script.js         # 前端 JavaScript 文件（功能实现代码二）
├── templates/            # Flask 模板文件夹
│   └── index.html        # 主 HTML 模板（功能实现代码三）
└── README.md             # 本文件
```

## 安装依赖库：
- Flask
- NetworkX
- PyVis
- CausalNex
   ```bash
   pip install Flask networkx pyvis causalnex
   ```


## 运行项目
1. **启动 Flask 应用程序**：
   ```bash
   python app.py
   ```

2. **打开浏览器**，访问以下地址：
   ```
   http://127.0.0.1:5001/
   ```

## 功能介绍
- **添加节点和边**：用户可以添加带有属性的节点和边。
- **删除节点和边**：用户可以删除现有的节点和边。
- **更新节点和边**：用户可以更新节点和边的属性。
- **可视化因果图**：应用程序使用 PyVis 生成交互式的因果图可视化。
- **日志记录**：所有操作都会被记录到日志文件中，便于调试和跟踪更改。

## 代码说明

### `app.py`
这是主 Flask 应用程序文件。它初始化 Flask 应用程序，定义处理用户请求的路由，并与 `CausalGraph` 类集成，用于操作因果图。

### `templates/index.html`
这是 Web 应用程序的主 HTML 模板文件，包含以下内容：
- 添加/删除/更新节点和边的输入框。
- 用于可视化因果图的按钮。
- 显示生成的因果图可视化的 `iframe`。

### `static/script.js`
这个 JavaScript 文件处理前端的用户交互：
- 绑定按钮的点击事件。
- 向 Flask 后端发送 AJAX 请求。
- 在每次操作后刷新可视化 `iframe`。

### `static/causal_graph.html`
这个文件由 `CausalGraph.visualize` 方法生成，包含因果图的交互式可视化内容。它会在 `index.html` 中的 `iframe` 中显示。

## 使用方法
1. **添加节点和边**：
   - 在输入框中输入节点名称和属性（如果有）。
   - 点击“添加节点”或“添加边”按钮将它们添加到图中。

2. **删除节点和边**：
   - 在输入框中输入节点名称或边的详细信息。
   - 点击“删除节点”或“删除边”按钮将它们从图中删除。

3. **更新节点和边**：
   - 在输入框中输入节点名称或边的详细信息以及新的属性。
   - 点击“更新节点”或“更新边”按钮修改它们的属性。

4. **可视化因果图**：
   - 点击“可视化因果图”按钮刷新 `iframe` 中的可视化内容。

增加边时添加一个属性表示"增边"
点击拒绝和接受按钮，做出对应操作
